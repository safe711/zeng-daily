服务器 证书安装

请在 Safari 浏览器里操作。证书现在通过公网 HTTPS 下载，不必先连接家庭 服务器；首次查看契约和备份照片时再连接家里的 Wi-Fi。

你仍在桌面的日课中。请复制下面的地址，手动打开 Safari 并粘贴到地址栏。

1. 下载描述文件

点击下载“日课家庭证书”证书

Safari 提示下载描述文件时，选择“允许”。如果下载后页面空白，请直接打开设置检查“已下载描述文件”。

2. 安装并信任

设置 → 已下载描述文件 → 安装。也可在通用 → VPN 与设备管理中找到它。

再进入设置 → 通用 → 关于本机 → 证书信任设置，开启“日课家庭证书”。

这个描述文件仅包含家庭 服务器 根证书，没有账户、访问密钥或设备管理权限。
